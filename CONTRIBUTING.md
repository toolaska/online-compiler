# Contributing to Toolaska Quick Compiler

Thank you for your interest in contributing to **Quick Compiler**! 

Quick Compiler is a free online code editor and playground hosted at **[https://compiler.toolaska.com](https://compiler.toolaska.com/)** designed to help developers write, test, debug, and preview HTML, CSS, JavaScript, and TypeScript live in the browser.

---

## 🧭 Ways to Contribute

1. **Bug Reports**: Open an issue describing compiler errors, runtime sandboxing quirks, or UI rendering glitches.
2. **Feature Suggestions**: Propose new capabilities (e.g., additional preprocessors, library imports, console features).
3. **Documentation & SEO**: Improve blog guides, fix typos, or suggest SEO and schema enhancements.
4. **Pull Requests**: Submit code improvements or optimizations.

---

## 🛠️ Contribution Workflow

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/toolaska/online-compiler.git
   cd online-compiler
   ```

2. **Create a Topic Branch**:
   ```bash
   git checkout -b feature/compiler-feature
   ```

3. **Make Your Changes**:
   - Ensure code is clean, readable, and well-documented.
   - Maintain strict client-side data privacy and secure iframe sandboxing.

5. **Commit with Clear Messages**:
   ```bash
   git commit -m "feat: add viewport dimension indicator"
   ```

6. **Push and Open a Pull Request**:
   Push to your branch and submit a PR to `master` (or `main`) on `toolaska/online-compiler`.
